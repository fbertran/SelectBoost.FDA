# Extract Selected Features or Groups

Returns the selected rows from
[`selection_map()`](https://fbertran.github.io/SelectBoost.FDA/reference/selection_map.md)
for stability-selection or SelectBoost fits.

## Usage

``` r
selected(x, ...)
```

## Arguments

- x:

  A fitted selection object.

- ...:

  Additional arguments passed to the relevant method.

## Value

A data frame.
