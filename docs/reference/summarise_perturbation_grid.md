# Summarize Perturbation-Grid Selection Surfaces

Summarize Perturbation-Grid Selection Surfaces

## Usage

``` r
summarise_perturbation_grid(x, level = NULL)
```

## Arguments

- x:

  A `fda_perturbation_grid` object.

- level:

  Optional selection level filter.

## Value

A compact data frame grouped by `q`, `c0`, and level.
