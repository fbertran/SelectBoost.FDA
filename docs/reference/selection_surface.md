# Extract a Selection Surface

Convenience wrapper around
[`as_selection_surface_data()`](https://fbertran.github.io/SelectBoost.FDA/reference/as_selection_surface_data.md).

## Usage

``` r
selection_surface(x, ...)
```

## Arguments

- x:

  A fitted selection object or perturbation grid.

- ...:

  Additional arguments passed to
  [`as_selection_surface_data()`](https://fbertran.github.io/SelectBoost.FDA/reference/as_selection_surface_data.md).

## Value

A selection-surface data frame.
