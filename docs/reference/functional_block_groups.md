# Block-Level Groups for Functional Predictors

Returns one group label per column, with each functional block defining
a group.

## Usage

``` r
functional_block_groups(x)
```

## Arguments

- x:

  Any input accepted by
  [`as_functional_matrix()`](https://fbertran.github.io/SelectBoost.FDA/reference/as_functional_matrix.md).

## Value

An integer vector of group memberships.
